# Marketing Funnel & Conversion Performance Analysis

## Project Overview
This project analyzes a bank marketing campaign dataset to understand customer response and conversion performance across different campaign segments.

## Objectives
- Calculate overall conversion rate
- Analyze conversion by communication channel
- Analyze conversion by job category
- Analyze conversion by age group
- Analyze conversion by campaign contact frequency
- Create an interactive Excel dashboard

## Key Metrics
- Total Leads/Contacts: 4,521
- Successful Responses: 521
- Overall Conversion Rate: 11.52%

## Analysis Performed
The project includes:
- Channel-wise conversion analysis
- Job-wise conversion analysis
- Age-wise conversion analysis
- Campaign-wise conversion analysis
- Excel dashboard and data visualizations

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Creation

## Files Included
- `Marketing_Funnel_Analysis.xlsx` – Excel analysis and dashboard
- `Marketing_Funnel_Analysis_Report.docx` – Detailed project report

## Conclusion
The analysis provides insights into campaign response patterns across communication channels, customer job categories, age groups, and campaign contact frequency.
